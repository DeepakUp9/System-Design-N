## Project 1: TCP Echo Server 
  this will teach you the core TCP workflow: connection setup, reading/writing bytes, client-server communication, and proper closing of sockets.

# Goal
Create a TCP server that:  
    1. Accepts multiple client connections.  
    2. Echoes back any data sent by the client.  
    3. Logs all traffic with client IP/port.  
    4. Closes connections gracefully.
